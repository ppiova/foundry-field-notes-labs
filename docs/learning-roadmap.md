# Learning roadmap

Updated 2026-10-15. This is a direction for the educational series, not a release schedule. Start with the [sample catalog](../README.md#samples) for labs you can run now.

## Available learning paths

Foundry Field Notes connects a concrete problem to tool selection, reproducible implementation, observable behavior, and verified limitations.

| Lab | Central question |
| --- | --- |
| [001 - Support Signal](../samples/01-support-signal/README.md) | How do I turn free-form text into a proposal my application can validate and a person can review? |
| [002 - Bid Review Queue](../samples/02-bid-review-queue/README.md) | How do I use bounded model choices and probabilities without mistaking an acceptance rule for correctness? |

Each lab has a no-Azure path. Live verification is dated separately and does not replace workload-specific evaluation.

## Planned direction

The [Coming soon catalog](../README.md#coming-soon) lists the proposed sequence and links to official Microsoft documentation: prompt agents, hosted agents and a toolbox, routines and memory, evaluation and optimization, voice, and an autopilot.

The plan continues Lab 002's bid-review scenario one capability at a time. Preview capabilities remain explicitly labeled. Each new lab needs current official evidence, a reproducible first-success path, a concrete reason for every service, and a separate subscription and spending decision.

Review the order monthly. A planned lab is not an implemented capability, a funding commitment, or authorization to provision Azure resources. No private issue tracker or maintainer deployment is required to use this roadmap.
