FOUNDRY FIELD NOTES / LAB 001
Support Signal
An educational demo of request classification and human review. This is not a production support system.
Simulation uses rules. Foundry mode uses Microsoft Agent Framework with Responses inference and a managed identity in Azure, or Azure CLI for local development. Cloud integration requires configuration and validation with your deployment.
Results stay in browser memory and are lost on reload. Approval records a local decision only. Export downloads the analysis and edits; it does not send messages.
The Azure deployment requires restricted Microsoft Entra sign-in. Local development has no application authentication and belongs on localhost. Use synthetic data.
